约定：本帖仅讨论涉及的几个词缀以及他们在打伤害过程中的影响，且仅有这些影响。

不讨论面板和其他特殊词缀（如暴击伤害、基础暴击伤害、最终伤害增强）。

（还是提了一句面板，在三楼：面板攻击力不影响伤害，不要被面板攻击力误导了。）

本文文字对所有装备都适用，数字是拿双飞燕艾尔莎举例。

## 首先明确几个名词（一个字、一个符号都不能有偏差）

- **攻击力倍率**：由禁锢、山姆领队、黄光环灵魂石等提供，双飞燕传奇特效加的也是这个，所有途径加在一起。
- **战术攻**：战术附带的战术攻，以及两个封印（攻击赐福封印、武器大师封印）、艾尔莎冠绝天赋（别问为什么，实测就是这样），所有途径加在一起。
- **武器攻击力**：武器的攻击力 + 烙印攻击力。
- **武器攻击力%**：武器、宝石上的"武器攻击力%"词缀，英雄勋章封印，所有途径加在一起。
- **额外攻击力**：咔叽天赋力量转攻击、战斗法则封印、黑生肖、禁锢、噬魂等宝石提供的攻击力。
- **伤害增强**：攻击者身上任何途径提供的伤害增强%词缀数值的总和（普攻伤害%、范围伤害%、物理伤害%、法术伤害%、近战伤害%、远程伤害%、武器系别伤害%、伤害增强%、先后攻伤害%、奇偶回合伤害%、白天黑夜伤害%、斩杀压制伤害%、每点能量增伤%、对 X 种族伤害%、小怪 Boss 伤害%、对异常状态伤害% 等等）。

## 这几个词缀生效的关系

二星双飞燕：

```
(1+攻击力倍率) * {额外攻击力 + 武器攻击力 * [(1+武器攻击力%)*1.75 + 战术攻]} * (1+伤害增强)
```

三星双飞燕：

```
(1+攻击力倍率) * {额外攻击力 + 武器攻击力 * [(1+武器攻击力%)*3.0625 + 战术攻]} * (1+伤害增强)
```

一共是三个乘数，乘法的关系！因此无论自身多大多小，只要单个乘数是百分比的提升，那么总伤害就是百分比的提升！

**第一个乘数：(1+攻击力倍率)**——本来是个挺稀有的属性，但双飞燕特殊，加了好多，但也是双飞燕特效值和攻速越高越好。

举例：8% 的双飞燕，一回合 a 十下，那就是一回合 80% 的攻击力倍率；第十回合后就是 800% 的攻击力倍率。(1+800%)/1 = 9，是第一回合的九倍伤害。

**第二个乘数：**

```
{额外攻击力 + 武器攻击力 * [(1+武器攻击力%)*3.0625 + 战术攻]}
```

只要艾尔莎不带噬魂，那么这个乘数可以近似于 (1.3 + 武器攻击力%)（假设战术攻为 90%）。

**第三个乘数：(1+伤害增强)**——封印的大部分伤害增加都是属于这个乘数。

在没有噬魂的情况下，(1.3 + 武器攻击力%) × (1 + 伤害增强)。武器攻击力% 和伤害增强的取舍是看哪个总数小，哪个小就优先打哪个。

```
(10000 + 10) * 10 = 100100
10000 * (10 + 10) = 200000
```
